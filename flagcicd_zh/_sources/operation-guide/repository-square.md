# 仓库广场

仓库广场展示平台中所有已注册的仓库，用户可以查看仓库的基本信息和运行状态。

## 访问路径

左侧导航栏 → **仓库广场**

![仓库广场列表](../static/04-repository-square-list.png)

## 列表字段

| 列名 | 说明 |
|------|------|
| 仓库名称 | 仓库完整名称（owner/repo 格式） |
| 描述 | 仓库描述信息 |
| 图标 | 代码托管平台标识（GitHub/GitLink） |
| 运行数 | 工作流运行次数 |
| 成功数 | 成功的工作流数量 |
| 失败数 | 失败的工作流数量 |
| 最近更新 | 仓库最后更新时间 |

## 操作说明

点击仓库卡片进入仓库详情页，查看工作流运行实例、仓库质量、制品等信息。
