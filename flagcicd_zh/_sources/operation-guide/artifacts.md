# 制品管理

制品管理模块用于管理平台中的构建产物，包括容器 {term}`镜像` 和 Python {term}`Wheel` 包。

## 容器镜像

容器镜像页面展示平台托管的所有 Docker 镜像。

### 访问路径

左侧导航栏 → **制品管理** → **容器镜像**

![容器镜像列表](../static/14-artifact-images.png)

### 搜索功能

支持按镜像名称搜索，输入关键词后按回车或点击搜索图标。

### 列表字段

| 列名 | 说明 | 支持操作 |
|------|------|----------|
| 镜像名称 | 镜像名称 | - |
| Tag | 镜像 {term}`Tag` | - |
| 类别 | 镜像类别 | - |
| 大小 | 镜像大小 | 支持排序 |
| 架构 | 支持 amd64、arm64 | - |
| 推送时间 | 镜像推送时间 | 支持排序 |
| 下载数 | 下载次数 | 支持排序 |

## Python 包

### 访问路径

左侧导航栏 → **制品管理** → **Python 包**

![Python 包列表](../static/10-artifacts-python.png)

### 搜索功能

支持按包名模糊搜索。

### 列表字段

| 列名 | 说明 | 支持操作 |
|------|------|----------|
| 包名 | Python 包名称 | - |
| 版本 | 包版本号 | - |
| Python 版本 | 支持的 Python 版本 | 支持排序 |
| 大小 | 包大小 | 支持排序 |
| 仓库 | 来源仓库 | - |
| 上传时间 | 上传时间 | 支持排序 |
