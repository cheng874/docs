# 资源规格

资源规格页面展示平台支持的所有计算资源规格，用户可以查看不同芯片类型和配置的资源详情。

## 访问路径

左侧导航栏 → **资源规格**

![资源规格列表](../static/13-resource-specs.png)

## 筛选条件

| 筛选项 | 说明 |
|--------|------|
| {term}`地域` | 按地域过滤（如：智源-北京大兴二、智源-北京大兴三） |
| {term}`可用区` | 按可用区过滤（如：可用区A、可用区F） |
| 卡型 | 按芯片类型过滤 |

## 列表字段

| 列名 | 说明 |
|------|------|
| {term}`地域` | 资源所在地域 |
| {term}`可用区` | 资源所在可用区 |
| 名称 | {term}`资源规格`名称 |
| 卡型 | 芯片类型标识 |
| 规格详情 | 详细的资源配置（卡数、CPU 核数、内存） |

## 支持的芯片类型

| 芯片 | 标识 | 说明 |
|------|------|------|
| 海光 DCU | Hygon_DCU-64GB | 国产 {term}`DCU` 加速卡 |
| 沐曦 MXC550 | MetaX_MXC550-64GB | 国产 {term}`GPU` |
| 摩尔线程 S5000 | Mthreads_MTT-S5000-80GB | 国产 {term}`GPU` |
| NVIDIA A100 | - | NVIDIA {term}`GPU` |
| 昇腾 Ascend910 | - | 华为 {term}`NPU` |

## 分页

- 默认每页显示 10 条
- 支持跳转到指定页码
