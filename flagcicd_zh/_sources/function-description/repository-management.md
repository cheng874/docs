# 仓库管理

仓库管理功能支持平台注册和管理代码仓库，提供仓库广场、我的仓库和成员管理三大模块，支持 GitHub 和 GitLink 两种代码托管平台。

## 概述

仓库管理是 FlagCICD 的核心功能之一，用户可以注册 GitHub 或 GitLink 仓库，管理仓库成员协作，查看工作流运行状态。

## 模块说明

| 模块 | 说明 |
|------|------|
| 仓库广场 | 显示全部仓库 |
| 我的仓库 | 根据仓库权限判断显示哪些仓库 |
| 成员管理 | 仓库支持多成员协作 |

## 成员管理规则

- 设置 tab 只有 {term}`平台管理员`/{term}`仓库管理员` 有权限查看
- 仓库创建者自动添加到成员管理
- 当前只有 {term}`仓库管理员` 一个角色

## GitLink 支持说明

FlagCICD 支持国产代码仓库 GitLink，但存在以下限制：

| 限制项 | 说明 |
|--------|------|
| 工作流运行列表 | 只显示名称 |
| 仓库质量 | GitLink 暂不支持 |
| 流水线效率 | GitLink 暂不支持 |
| {term}`Workflow` 高级语法 | 不支持 outputs、matrix、concurrency |
| Runner 注册 | 需要官方申请组织下的 token |
