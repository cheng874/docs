# 制品管理

制品管理功能用于管理平台构建产物，包括 Docker 容器镜像和 Python Wheel 包，提供搜索、筛选和排序功能。

## 概述

制品管理模块托管 CI/CD 流程产生的构建产物，用户可以查看和下载 Docker 镜像与 Python 包。

## 容器镜像

容器镜像页面展示平台托管的所有 Docker 镜像。

| 功能 | 说明 |
|------|------|
| 搜索 | 按镜像名称搜索 |
| 筛选 | 支持类别筛选 |
| 排序 | 大小、推送时间、下载数支持排序 |
| 架构 | 支持 amd64、arm64 |

## Python 包

Python 包页面展示平台托管的 {term}`Wheel` 包。

| 功能 | 说明 |
|------|------|
| 搜索 | 支持包名模糊搜索 |
| 排序 | Python 版本、大小、上传时间支持排序 |
