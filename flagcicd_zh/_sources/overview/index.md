# 平台概述

FlagCICD 是一个面向多芯片开源项目的统一 {term}`CI/CD` 平台，核心目标是解决 AI 基础设施"碎片化"挑战，实现大模型软件栈从 CUDA 向国产芯片的高效迁移与适配。

## 核心价值

将跨芯片适配从一个依赖个人经验、结果不确定、成本高昂的"艺术"，转变为一个**标准化、自动化、可量化**的"工程过程"，为国产算力生态提供可信任、可持续的发展基础。

## 三层架构

| 层级 | 核心能力 | 说明 |
|------|----------|------|
| 基础层 | 标准化 CICD 流程 | 环境构建、依赖管理、验证自动化 |
| 智能层 | AI 驱动自动迁移 | "分析 - 迁移 - 验证 - 优化"闭环 |
| 平台层 | 资源调度与云服务 | 在线迁移、测试、发布的开箱即用体验 |

## 平台能力

- 提供多种异构算力 {term}`Runner`，支持用户配置化接入 GitHub CI/CD 流水线
- 支持流水线报告展示（{term}`Coverage`、{term}`Benchmark` 等），支持用户自定义报告展示
- 支持制品上传和托管，包括 Docker {term}`镜像`、Python {term}`Wheel` 包
- 支持用户测例上传和管理
- 支持 GitHub、GitLink 等多代码托管平台接入

## 支持的芯片生态

平台支持以下国产芯片：

| 芯片类型 | 说明 |
|----------|------|
| 华为昇腾 | NPU |
| 海光 DCU | 深度计算单元 |
| 沐曦 MXC550 | GPU |
| 摩尔线程 S5000 | GPU |
| NVIDIA A100 | GPU |
