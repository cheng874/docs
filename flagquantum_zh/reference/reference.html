契约与策略#

主题

定义位置

运行时证据字段

带版本的运行时契约；这套词汇是契约，不是运行发生过的证明

实测基准证据

带来源信息的审计产物；计划与夹具不算证据

支持的 Python 与依赖

包元数据：Python 3.10–3.12，PyTorch 2.5–2.13

结论边界#

本地执行、已注册的下沉支持、分布式开发探针与发布级可扩展性是彼此独立的结论。注册了下沉只证明某算子可在某路径上执行，并不证明该路径在生产规模上可用。分布式与加速卡结论还额外要求由运行时生成的证据，并通过仓库的基准审计与发布策略。

规划中的能力属于路线图文档；在可执行清单与测试出现之前，不会列为受支持。
