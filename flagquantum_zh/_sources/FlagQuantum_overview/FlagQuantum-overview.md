# FlagQuantum 概览

FlagQuantum 是一个基于 PyTorch 构建的高性能分布式量子状态向量模拟器，支持跨多个 GPU 的量子电路模拟，具备自动分片和重新分片功能，同时也能无缝支持真实量子硬件执行。它是 FlagOS 生态系统的一部分——一个统一的、开源的 AI 系统软件栈，通过无缝集成各种模型、系统和芯片，促进开放技术生态的发展。

## 为什么选择 FlagQuantum？

随着量子电路的量子比特数量和深度不断增加，经典模拟的成本变得极其高昂。FlagQuantum 通过分布式 GPU 加速来解决这一挑战，同时保持灵活、可扩展的架构。它弥合了模拟与真实硬件之间的鸿沟，实现了从开发到部署的无缝过渡。
