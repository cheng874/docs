# 发布说明

## v0.1.0


- **新增功能**

  - FlagQuantum 初始版本发布，一个基于 PyTorch 构建的高性能分布式量子状态向量模拟器。

  - 使用 `torch.distributed` 中的 `DTensor` 实现分布式状态向量模拟，支持多 GPU 执行。

  - 自动重新分片，以最小化门操作期间的通信开销。

  - 全面的门集合，包括泡利门、克利福德门、旋转门和受控门，支持参数化。

  - 可逆反向传播，用于内存高效的梯度计算。

  - 自定义门注册系统，用于扩展库。

  - 后选择和噪声模型，包括去极化噪声。

  - 灵活的数据编码，支持角度编码、振幅编码和基态编码方案。

  - 专业的量子电路可视化功能。

  - OpenQASM 2.0/3.0 导出器，用于真实量子硬件和跨框架执行。
