# PyTorch-Plugin-FL Overview

`torch_fl` is a custom PyTorch device plugin based on the PrivateUse1 extension mechanism, registering [FlagGems](https://github.com/flagos-ai/FlagGems) high-performance Triton operators as the `flagos` device backend for unified multi-chip support.
