# FlagScale v1.0.0 Release Notes

## Highlights

- **Unified FlagScale CLI**: Introduced a unified FlagScale CLI as the single entry point for all operations, with unified multi-chip training support across NVIDIA GPU, Ascend, and MUSA.
- **VeRL-FL & Expanded Model Support**: Replaced third-party verl with [VeRL-FL](https://github.com/flagos-ai/verl-FL) and expanded model support to include Qwen3-VL, Qwen2.5-VL, GR00T N1.5, and DeepSeek Engram.
- **Enhanced CI/CD**: Enhanced CI/CD coverage with Megatron-LM-FL integration tests and automated CLI validation workflows.
